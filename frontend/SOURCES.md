## 💰 Dette Publique Française

- **Fiabilité** : ⭐⭐⭐⭐⭐ (source gouvernementale officielle)

### Méthodologie de Calcul

#### Dette Totale
```
Dette actuelle = 3 100 000 000 000 € (3 100 milliards €)
Base : Chiffres consolidés T4 2023
```

#### Augmentation par Seconde
```
Déficit annuel 2023 ≈ 150 milliards €
Augmentation/seconde = 150 Mds € / (365,25 × 24 × 3600) ≈ 2 733 €/s

Note : Cette valeur est une moyenne annualisée. 
En réalité, la dette varie de manière non linéaire selon 
les emprunts et remboursements de l'État.
```

#### Dette par Habitant
```
Dette par habitant = 3 100 Mds € / 67,97 millions
                   ≈ 45 600 €
```

#### Dette par Actif
```
Dette par actif = 3 100 Mds € / 29,9 millions
                ≈ 103 600 €
```

#### Ratio Dette/PIB
```
Ratio = (Dette / PIB) × 100
      = (3 100 Mds € / 2 782 Mds €) × 100
      ≈ 111,4 %

Référence : Critère de Maastricht = 60% max
```

#### Intérêts de la Dette
```
Intérêts annuels = 52,4 milliards € (données 2023)
Intérêts/seconde = 52,4 Mds € / (365,25 × 24 × 3600)
                 ≈ 1 661 €/s
```

### Limites et Précautions

⚠️ **Simplifications effectuées :**
1. Le compteur augmente de manière linéaire, alors que dans la réalité :
   - Les emprunts se font par émissions ponctuelles d'obligations
   - Des remboursements ont également lieu
   - Le solde varie quotidiennement selon la trésorerie de l'État

2. Le calcul de contribution par habitant est **théorique** :
   - La charge fiscale n'est pas répartie uniformément
   - L'impôt est progressif (plus le revenu est élevé, plus on contribue)
   - Certains impôts sont indirects (TVA, taxes sur les carburants, etc.)

3. Les intérêts de la dette varient selon :
   - Les taux directeurs de la BCE
   - La confiance des marchés (spread)
   - La maturité des titres

### Méthodologie de Cartographie

#### Critères de Sélection des Entités

**Think Tanks inclus :**
- Influence reconnue dans le débat public
- Présence régulière dans les médias
- Diversité des orientations politiques (gauche, droite, centre, libéral)

**Milliardaires inclus :**
- Fortunes supérieures à 5 milliards € (ou influence médiatique majeure)
- Propriété ou participation significative dans des médias
- Soutien documenté à des think tanks

**Médias inclus :**
- Audience nationale significative
- Présence dans le débat politique
- Presse écrite, radio, TV

#### Types de Liens Identifiés

1. **Financement Think Tank ↔ Milliardaire**
   - Source : Rapports annuels, articles de presse
   - Critère : Don significatif ou partenariat officiel

2. **Propriété Milliardaire → Média**
   - Source : Registres publics (AMF, Arcom), organigrammes
   - Critère : Actionnaire majoritaire ou de référence

3. **Présence Médiatique Think Tank → Média**
   - Source : Analyse de contenu, interviews régulières
   - Critère : Présence récurrente d'experts du think tank

### Limites et Biais Potentiels

⚠️ **Simplifications nécessaires :**

1. **Structures de propriété complexes**
   - Les groupes utilisent des holdings, filiales, participations croisées
   - La cartographie présente une version simplifiée des liens de contrôle
   - Exemple : Xavier Niel ne possède pas "Le Monde" directement, mais via la société NJJ aux côtés de Matthieu Pigasse et Pierre Bergé (historique)

2. **Intensité des liens non quantifiée**
   - Un lien "financement" peut représenter 10% ou 80% du budget
   - Un lien "présence médiatique" peut être 1 ou 50 passages/an
   - La visualisation ne distingue pas ces nuances

3. **Influence ≠ Contrôle**
   - Un financeur n'a pas nécessairement de pouvoir éditorial
   - Les journalistes et chercheurs ont des garanties d'indépendance (chartes, statuts)
   - Les liens affichés sont **factuels** mais ne préjugent pas de l'indépendance réelle

4. **Évolution temporelle**
   - Les données sont celles connues au moment de la création (2024)
   - Les actionnariats, directions, financements évoluent
   - Une mise à jour régulière serait nécessaire

5. **Sélection non exhaustive**
   - Seuls les acteurs majeurs sont représentés
   - De nombreux autres think tanks, médias locaux, et acteurs existent
   - Le choix vise la pédagogie, pas l'exhaustivité

### Orientations Politiques

Les orientations indiquées (ex: "centre-droit", "social-démocrate") sont basées sur :
- L'auto-déclaration des organisations (quand disponible)
- Les analyses de politologues (Sciences Po, CNRS)
- Les articles de presse spécialisée

⚠️ Ces catégories sont **indicatives et simplificatrices**. Le spectre politique est complexe et les think tanks peuvent avoir des positions variées selon les sujets.

## 🔍 Vérification des Sources

### Comment Vérifier les Informations

Pour chaque affirmation du site, vous pouvez :

1. **Consulter les sources primaires** listées ci-dessus
2. **Rechercher dans les archives presse** :
   - Europresse (abonnement universitaire/bibliothèque)
   - Archives en ligne des médias
3. **Vérifier les registres publics** :
   - HATVP pour les lobbies
   - AMF pour les actionnariats
   - Arcom pour les médias audiovisuels

### Signaler une Erreur

Si vous identifiez une erreur, une imprécision ou une source obsolète :
- Ouvrez une **Issue GitHub** avec :
  - La donnée concernée
  - La source contradictoire
  - Une proposition de correction
- Les contributions documentées sont les bienvenues !

## ⚖️ Éthique et Déontologie

### Principes Appliqués

1. **Transparence** : Toutes les sources sont citées
2. **Factualité** : Seuls les liens documentés sont affichés
3. **Pluralisme** : Diversité des orientations représentées
4. **Pédagogie** : Simplification assumée et expliquée
5. **Non-jugement** : Pas de qualificatif moral sur les acteurs

### Ce que le Site N'est PAS

- ❌ Une enquête journalistique approfondie
- ❌ Un outil de dénonciation ou de polémique
- ❌ Une analyse exhaustive de tous les acteurs
- ❌ Une preuve d'influence ou de manipulation

### Ce que le Site EST

- ✅ Un outil pédagogique de visualisation
- ✅ Une compilation de données publiques
- ✅ Une invitation à l'esprit critique
- ✅ Un support pour un débat démocratique éclairé
