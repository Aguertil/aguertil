# 📊 Ajustement à l'Inflation - Méthodologie

## 🎯 Objectif

Comparer équitablement la dette accumulée par chaque président en tenant compte de l'érosion monétaire due à l'inflation. Un euro de 1950 n'a pas la même valeur qu'un euro de 2024.

## 💡 Principe

Les valeurs sont converties en **euros constants 2024** en appliquant un coefficient multiplicateur basé sur l'inflation cumulée depuis la période du mandat.

### Exemple concret

**François Mitterrand (1981-1995)**
- Dette nominale accumulée : **414 milliards €**
- Coefficient d'inflation : **×3.5**
- Dette ajustée 2024 : **1 449 milliards €**

Cela signifie que les 414 milliards d'euros empruntés entre 1981 et 1995 équivalent à un pouvoir d'achat de 1 449 milliards d'euros en 2024.

## 🔬 Méthodologie Détaillée

### Sources des coefficients

Les coefficients sont calculés à partir de :
- **INSEE** : Indices des prix à la consommation (IPC)
- **Banque de France** : Données d'inflation historique
- **Eurostat** : Données harmonisées post-euro

### Formule de calcul

```
Dette ajustée = Dette nominale × Coefficient inflation
```

Où le coefficient inflation est calculé comme :

```
Coefficient = IPC_2024 / IPC_moyenne_période
```

### Exemple détaillé : Mitterrand

**Période** : 1981-1995 (14 ans)

**Dette nominale** : 414 milliards €
- Dette début (1981) : 356 Mds €
- Dette fin (1995) : 770 Mds €
- Augmentation : 414 Mds €

**Inflation moyenne de la période** : ~6.5% par an

**Inflation cumulée** :
```
(1 + 0.065)^14 ≈ 2.43
```

**Ajustement 1995 → 2024** :
```
Inflation 1995-2024 ≈ 1.44
```

**Coefficient total** :
```
2.43 × 1.44 ≈ 3.5
```

**Dette ajustée** :
```
414 Mds € × 3.5 = 1 449 Mds €
```

## 💭 Interprétation et Limites

### ✅ Ce que l'ajustement montre

- **Pouvoir d'achat réel** : Quelle serait la dette en euros d'aujourd'hui
- **Comparaison équitable** : Neutralise l'effet de l'érosion monétaire
- **Contexte historique** : Révèle l'impact des périodes de forte inflation

### ⚠️ Limites à considérer

1. **Contexte économique** : L'inflation n'est qu'un facteur parmi d'autres
   - Guerres, crises, cycles économiques
   - Décisions législatives multi-gouvernements
   - Évolution du PIB et de la population

2. **Dette vs PIB** : Le ratio dette/PIB est parfois plus pertinent
   - Mesure la capacité de remboursement du pays
   - Prend en compte la croissance économique

3. **Choix monétaires** : L'inflation peut être une politique délibérée
   - Années 70-80 : Inflation élevée acceptée
   - Post-2000 : Inflation contrôlée par la BCE

4. **Panier de référence** : L'IPC reflète la consommation moyenne
   - Ne capture pas tous les changements de qualité de vie
   - Structure de consommation différente entre époques

## 🎓 Conclusion

L'ajustement à l'inflation révèle que **François Mitterrand** détient le record de dette accumulée en termes réels, devant VGE et Macron. 

Cependant, une analyse complète doit également considérer :
- Le **contexte économique** (crises, guerres)
- Le **ratio dette/PIB** (capacité de remboursement)
- La **durée du mandat** (14 ans pour Mitterrand vs 5 pour Sarkozy)
- Les **politiques héritées** des gouvernements précédents

## 📱 Utilisation dans l'application

### Frontend

Un **toggle switch** permet de basculer entre :
- **Euros nominaux** (valeurs brutes historiques)
- **Euros constants 2024** (valeurs ajustées)

```jsx
// Exemple d'utilisation
<Toggle 
  onChange={(adjusted) => setUseAdjustedValues(adjusted)}
  label={adjusted ? "Euros constants 2024" : "Euros nominaux"}
/>
```

### API

Paramètre `adjusted=true` disponible sur :

```bash
# Liste des présidents
GET /api/presidents?sortBy=debtIncrease&order=desc&adjusted=true

# Classement
GET /api/presidents/ranking/debtIncrease?adjusted=true
```

**Réponse** :
```json
{
  "adjusted": true,
  "presidents": [
    {
      "name": "François Mitterrand",
      "debtIncrease": 414000000000,
      "debtIncreaseAdjusted": 1449000000000,
      "inflationCoefficient": 3.5
    }
  ],
  "note": "Dette ajustée à l'inflation en euros constants 2024..."
}
```
